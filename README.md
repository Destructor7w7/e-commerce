# 🛍️ E-commerce Personal (React & APIs)

**Un proyecto personal de comercio electrónico moderno construido con React y consumiendo APIs para simular una experiencia de compra completa.**

## ✨ Descripción General

Este proyecto es una **Single Page Application (SPA)** de e-commerce desarrollada con **React**. Su objetivo principal es demostrar mi competencia en el **desarrollo frontend**, el **manejo de estados complejos**, la **gestión de rutas** y, críticamente, la **integración robusta con servicios backend simulados** a través de APIs.

> **Inspiración:** La arquitectura y la limpieza del código están inspiradas en las **soluciones digitales escalables y personalizadas** que ofrece **LOISLIVE.TECH**, enfocándome en un desarrollo de alta calidad y fácil mantenimiento.

### Características Destacadas

* **Catálogo Interactivo:** Visualización de productos con filtros y búsqueda.
* **Carrito de Compras:** Funcionalidad completa para añadir, actualizar y eliminar artículos.
* **Gestión de Estado:** Manejo eficiente del estado global de la aplicación.
* **Consumo de APIs:** Fetching de datos de productos y simulación de transacciones de compra.
* **Diseño Responsivo:** Interfaz adaptable a diferentes tamaños de pantalla (Desktop, Tablet, Móvil).

## 🛠️ Tecnologías Utilizadas

| Categoría | Tecnología | Descripción |
| :--- | :--- | :--- |
| **Frontend Principal** | **React** | Biblioteca fundamental para la construcción de la UI. |
| **Lenguaje** | **JavaScript (ES6+)** |gPara la lógica del lado del cliente. |
| **Estilización** | **[EJ: Styled Components / Tailwind CSS / CSS Modules]** | Define el look and feel de la aplicación. |
| **Gestión de Estado** | **[EJ: React Context / Redux / Zustand]** | Manejo centralizado del estado (ej. carrito, usuario). |
| **Enrutamiento** | **React Router DOM** | Para la navegación fluida entre vistas (productos, carrito, checkout). |
| **Consumo de Datos** | **Axios / Fetch** | Herramienta para la comunicación HTTP con las APIs. |
